# Versão 1.63.0

_Publicada em 30/08/2026._

## ✨ Novidades

- **Espiar conversa**: o Administrador da empresa agora pode **abrir conversas
  de outros atendentes sem marcar como lida**. O cliente não vê os ticks
  azuis e o responsável continua vendo a conversa como não lida. Acima da
  barra de mensagem aparece o interruptor **Modo: Espiar conversa** — com ele
  ligado, a conversa fica somente leitura. O modo fica salvo no seu
  navegador e começa desligado. A permissão existe só no cargo Administrador.

📖 **Saiba mais:** [Mensagens](../msg.md) · [Funções e permissões](../configuracao/usuarios/funcao.md)

## 🔧 Melhorias

- Em **Cargos**, a permissão **Espiar conversas (ler sem marcar como lida)**
  aparece só no cargo **Administrador**. Os demais cargos não recebem essa
  opção.
