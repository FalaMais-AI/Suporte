# Versão 1.77.2

_Publicada em 15/09/2026._

## ✨ Novidades

**Aviso e template ao transferir para a API Oficial**

Ao transferir um atendimento para um canal da API Oficial, o sistema agora
avisa que a janela de 24 horas vale por número: as mensagens que o cliente
enviou no canal anterior não liberam respostas livres no novo número.

Quando a janela de 24 horas está fechada, o seletor de templates aprovados abre
automaticamente depois da transferência, para reengajar o contato com
segurança — em vez de uma resposta livre que seria recusada pelo WhatsApp.

📖 **Saiba mais:** [Canais — WhatsApp](../configuracao/canais.md) · [Mensagens](../msg.md).

**Histórico de troca de canal no atendimento**

O histórico da conversa passa a mostrar quando o atendimento mudou de canal
(por exemplo, "Canal transferido de Savassi - SC para Brasília - CS"), com
quem fez a transferência. O mesmo registro aparece no histórico do contato,
facilitando entender por onde cada conversa passou.

📖 **Saiba mais:** [Mensagens](../msg.md).

## 🐛 Correções

**Respostas após transferir para a API Oficial**

Corrigimos um problema em que, ao transferir um atendimento para a API Oficial,
era possível tentar enviar uma resposta livre mesmo com a janela de 24 horas
fechada no novo número. A mensagem aparecia como falha com o aviso
"Re-engagement message". Agora o sistema reconhece que a janela foi zerada para
o novo canal e orienta o envio de um template aprovado.

📖 **Saiba mais:** [Canais — WhatsApp](../configuracao/canais.md) · [Mensagens](../msg.md).
