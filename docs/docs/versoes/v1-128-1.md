# Versão 1.128.1

_Publicada em 04/11/2026._

## 🔧 Melhorias

- Quando uma tela não consegue carregar, agora existe a opção "Detalhes técnicos para o suporte". Ao nos enviar esse texto, conseguimos identificar a causa com mais rapidez.

## 🐛 Correções

- Mensagens rápidas só com áudio gravado voltaram a ser enviadas. Antes, a prévia mostrava apenas o botão de cancelar ativo. Agora você também pode ouvir a gravação na prévia antes de enviar.
- Templates enviados pela API oficial do WhatsApp agora aparecem na conversa com o texto completo, mesmo quando o template ainda não tinha sido sincronizado. Antes, a conversa podia mostrar só "Template:" seguido do nome.
