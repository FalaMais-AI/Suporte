## ✨ Novidades

- O usuário `SUPER_ADMIN` agora consegue gerar, consultar, rotacionar e revogar
  a chave de acesso da própria instalação pelo painel local. O segredo aparece
  somente no momento da criação ou rotação.
- A API Super Admin está disponível no FalaMais SaaS e em cada instalação
  On-Premise, com o mesmo padrão de autenticação, paginação e operações.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)

## 🔧 Melhorias

- As operações que dependem da autorização central agora passam pelo fluxo
  oficial de aprovação da FalaMais. No On-Premise, a instalação mantém o token
  local e usa uma conexão segura para falar com o Control Plane.
- Criações repetidas podem ser retomadas com segurança, sem duplicar contas ou
  vincular uma instalação a outro cliente.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)

## 🐛 Correções

- Leituras do On-Premise passaram a usar o limite correto, e as escritas
  continuam exigindo uma chave de idempotência.
- Repetições com o mesmo conteúdo agora são reconhecidas mesmo quando a ordem
  dos campos JSON muda.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)
