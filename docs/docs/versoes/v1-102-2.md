# Versão 1.102.2

_Publicada em 16/10/2026._

## 🐛 Correções

### Ligações para contatos com vários aparelhos

- Ligar pelo FalaMais para um contato que usa o WhatsApp em mais de um
  aparelho (por exemplo, celular e computador) agora funciona. Antes, a
  ligação podia cair logo no primeiro segundo, mesmo com o celular do contato
  tocando, e aparecia como falha no histórico.

📖 **Saiba mais:** [Ligações pelo WhatsApp](../ligacoes.md)
