# Versão 1.115.5

_Publicada em 28/10/2026._

## 🐛 Correções

- Mensagens rápidas agora aceitam vídeos e arquivos de até 50 MB. Antes, um arquivo acima de 20 MB era salvo incompleto: a mensagem rápida parecia pronta, mas o vídeo não abria e o envio falhava, inclusive nos follow-ups. Agora o arquivo é salvo inteiro e, se passar de 50 MB, você recebe um aviso na hora de anexar, com a orientação de comprimir o vídeo. Se algum vídeo seu aparecer como indisponível, anexe o arquivo de novo.
