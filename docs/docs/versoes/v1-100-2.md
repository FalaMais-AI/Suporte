# Versão 1.100.2

_Publicada em 13/10/2026._

## 🔧 Melhorias

### Caixa de entrada mais leve e rápida

- Abrir uma conversa deixou de gerar pedidos repetidos ao servidor a cada
  poucos segundos. A conversa continua sendo marcada como lida ao abrir e
  quando chega uma mensagem nova, mas sem trabalho desnecessário. Isso deixa
  a plataforma mais rápida para todos, principalmente nos horários de pico.
- Mensagens recebidas pelo WhatsApp são processadas mais rapidamente.
- A lista de conversas e a fila são atualizadas a cada poucos segundos, em
  vez de a cada mensagem, e abas em segundo plano só se atualizam quando você
  volta para elas. A conversa aberta continua atualizando na hora.
