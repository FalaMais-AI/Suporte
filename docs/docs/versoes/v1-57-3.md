# Versão 1.57.3

_Publicada em 23/08/2026._

## 🐛 Correções

- Enquanto uma resposta ainda está começando, o Assistente IA agora mostra um
  único indicador de carregamento no próprio ponto de atividade. Isso deixa
  claro que ele está trabalhando, sem parecer que ficou parado.
- A mensagem de andamento continua disponível mesmo em dispositivos que usam
  movimento reduzido.
