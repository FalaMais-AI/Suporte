# Versão 1.45.2

_Publicada em 11/08/2026._

## 🐛 Correções

- Ao editar um contato sem alterar suas etiquetas, as etiquetas existentes
  continuam preservadas.
- O CPF/CNPJ agora só é removido quando você pede explicitamente para limpar
  esse campo; salvar o contato sem mexer nele não apaga o documento.
