# Versão 1.58.0

_Publicada em 25/08/2026._

## ✨ Novidades

- Os contatos sincronizados pela Maqplan agora recebem a etiqueta **Maqplan**
  automaticamente. Isso facilita identificar a origem do contato, filtrar a
  base e organizar automações do time.

📖 **Saiba mais:** [Contatos importados pela Maqplan](../configuracao/integracoes-externas/maqplan.md)

## 🔧 Melhorias

- Quando sua empresa já usa uma etiqueta Maqplan, ela é mantida para preservar
  os filtros e automações que você já configurou.

📖 **Saiba mais:** [Contatos importados pela Maqplan](../configuracao/integracoes-externas/maqplan.md)

## 🐛 Correções

- A identificação de origem agora respeita a empresa do contato, mantendo os
  dados e etiquetas organizados no espaço de trabalho correto.

📖 **Saiba mais:** [Contatos importados pela Maqplan](../configuracao/integracoes-externas/maqplan.md)
