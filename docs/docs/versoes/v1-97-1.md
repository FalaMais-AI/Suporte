# Versão 1.97.1

_Publicada em 08/10/2026._

## 🐛 Correções

### Ligações pelo WhatsApp mais estáveis

- Ligações atendidas não são mais encerradas sozinhas depois de um minuto e
  meio de conversa. A ligação agora segue até alguém desligar.
- Ao conectar uma linha para ligações, o QR Code aparece em poucos segundos e
  se renova sozinho enquanto a tela estiver aberta. Se um código expirar, o
  próximo aparece automaticamente, sem precisar clicar em nada.
- Quando o número chamado recusa a ligação ou está ocupado, a tela mostra
  "Ocupado ou recusado pelo número chamado".
