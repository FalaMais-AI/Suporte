# Versão 1.102.0

_Publicada em 14/10/2026._

## ✨ Novidades

- Nos follow-ups, a nova variável `{{primeiro_nome}}` coloca só o primeiro
  nome do contato na mensagem ("Oi, Ana!" em vez de "Oi, Ana Paula Souza!").
  Quando o nome do contato no WhatsApp é um número ou só emojis, ela fica
  vazia, para a mensagem não sair estranha.
- Agora você pode definir um texto reserva para qualquer variável, usado
  quando o dado estiver faltando. Por exemplo, `{{primeiro_nome|tudo bem}}`
  vira "Ana" ou, se não houver nome, "tudo bem". Funciona na mensagem fixa e
  nos parâmetros de templates do WhatsApp Oficial, que não podem ficar vazios.
