# Versão 1.106.1

_Publicada em 20/10/2026._

## 🔧 Melhorias

- As atualizações do sistema agora acontecem sem tirar o FalaMais do ar. Você
  pode continuar atendendo, enviando mensagens e salvando normalmente enquanto
  uma nova versão é instalada.

## 🐛 Correções

- As mensagens de erro nos funis e nas etapas ficaram mais claras e dizem o
  que fazer. Por exemplo, ao tentar excluir uma etapa que ainda tem
  negociações, o sistema explica que é preciso mover as negociações para outra
  etapa antes.
- Ao criar ou editar uma etapa, quando algo não dá certo, agora aparece o
  motivo, em vez de um aviso genérico.
