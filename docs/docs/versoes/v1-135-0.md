# Versão 1.135.0

_Publicada em a definir na publicação._

## ✨ Novidades

### Busca de contato por CPF ou CNPJ na API

- Quem integra com a API agora encontra um contato pelo CPF ou CNPJ, com busca exata.
- A busca encontra o contato que está cadastrado só com números. Cadastros com pontuação entram numa atualização seguinte.

## 🔧 Melhorias

### Sua chave de IA personalizada fica privada

- A chave de IA personalizada da empresa não aparece mais para os membros da equipe.

### Limites de uso da API por chave

- Cada chave de API tem o próprio limite de uso, com aviso claro quando o limite é atingido.
- As respostas trazem quanto ainda resta e quando o limite volta, para o integrador se organizar.
- **Atenção para integradores:** cada chave tem o seu próprio limite. O limite por endereço de rede continua valendo antes da autenticação, como proteção: um endereço com muitas chaves ainda pode ser limitado.

### Tour de boas-vindas mais flexível

- Você pode sair do tour a qualquer momento, inclusive com a tecla Esc, sem perder a demonstração.
- Passos que não podem ser abertos no momento são pulados.

### Acesso às credenciais do WhatsApp Oficial

- Só quem tem permissão para gerenciar os canais vê e altera as credenciais do WhatsApp Oficial.

## 🐛 Correções

### Relatórios não entram mais em loop

- Abrir a página de relatórios deixa de redirecionar sem parar entre as telas.

### Ligações recebidas aparecem nas telas certas

- Ofertas de ligação recebida agora aparecem também nas telas de fluxo e na aba que você está vendo.

### Campanhas registram cada envio

- Antes de enviar, cada destinatário da campanha passa a ser registrado.

### Consulta de atendimentos com limite de tempo

- A consulta de atendimentos da API tem prazo e limite de registros, para não demorar sem fim em contas com muito histórico.

### Editor de fluxos mais acessível

- As caixas de mensagem do editor de fluxos têm nome para leitores de tela.
