# Versão 1.63.1

_Publicada em 30/08/2026._

## 🐛 Correções

- **Espiar conversa**: o interruptor **Modo: Espiar conversa** agora fica
  no **topo da lista de conversas** (incluindo Fila e Grupos). Só quem
  tem essa permissão no cargo (Administrador, se estiver marcada) vê o
  controle — ligue **antes** de abrir o atendimento para a conversa não
  ser marcada como lida. Dentro da conversa aparece só o aviso de que o
  modo está ativo.
