# Versão 1.106.0

_Publicada em 20/10/2026._

## ✨ Novidades

### Enviar mensagem para um grupo do WhatsApp nos fluxos

- Nos fluxos de automação há uma nova etapa: **Enviar WhatsApp para grupo**.
  Ela avisa um grupo da equipe, por exemplo a recepção, quando algo acontece
  no funil. O contato do fluxo não recebe nada.
- Você escolhe o número que envia e procura o grupo pelo nome. Aparecem os
  grupos em que esse número participa, com a quantidade de participantes.
- Funciona com números conectados por QR Code.
- Antes de salvar, você vê como a mensagem vai chegar no grupo, preenchida
  com um contato de exemplo.
- Lembre que todos do grupo leem a mensagem. Se ela tiver dados de saúde do
  paciente, use só em grupos da equipe.

📖 **Saiba mais:** [Fluxos](../automacao/fluxo.md)

### Dados do contato sem código nas mensagens

- Nas mensagens dos fluxos, os dados do contato aparecem com o nome, como
  **Nome do contato** ou **Última nota do negócio**, em vez de códigos entre
  chaves.
- Clique em **Inserir dado** ou digite **/** no meio do texto para escolher
  um dado. Cada opção mostra um exemplo do que vai aparecer.
- Cada dado é uma etiqueta que se apaga inteira, então não tem como digitar
  errado. Os fluxos que você já tem continuam funcionando e passam a mostrar
  as etiquetas.

📖 **Saiba mais:** [Fluxos](../automacao/fluxo.md)

## 🐛 Correções

- Quando um contato não tem algum dado usado na mensagem, o fluxo agora envia
  o texto sem esse dado. Antes, o cliente podia receber um código entre chaves
  no lugar.
- As mensagens de erro nos detalhes da negociação ficaram mais claras e dizem
  o que fazer para resolver.
