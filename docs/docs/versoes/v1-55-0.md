# Versão 1.55.0

_Publicada em 22/08/2026._

## ✨ Novidades

- O Assistente IA ganhou uma conversa mais estável para acompanhar pesquisas,
  análises e ações dentro do sistema.

## 🔧 Melhorias

- Agora o andamento de uma consulta aparece em uma única sequência, atualizada
  conforme a resposta chega.
- Quando você estiver lendo mensagens anteriores, o painel respeita sua
  posição e oferece um atalho para voltar ao conteúdo mais recente.

## 🐛 Correções

- Corrigimos estados repetidos de carregamento e o espaço de resposta vazio que
  podia aparecer antes da conclusão de uma consulta.
