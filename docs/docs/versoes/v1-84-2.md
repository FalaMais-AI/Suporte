# Versão 1.84.2

_Publicada em 25/09/2026._

## 🔧 Melhorias

- Mensagens e decisões dos Fluxos com IA passam a considerar as orientações do prompt principal publicado para a conexão, a instrução do nó e as mensagens recentes da conversa.
- A etapa **Aguardar** ganhou uma opção para reiniciar a espera quando houver nova atividade na conversa.

📖 **Saiba mais:** [Fluxos](../automacao/fluxo.md) · [Prompt do assistente](../assistente/prompt.md)

## 🐛 Correções

- Uma decisão da IA sem resposta clara não libera o envio do Fluxo.
- Fluxos configurados para respeitar a pausa deixam de enviar quando a conversa está atribuída a uma pessoa. Uma nova mensagem recebida antes do envio também impede que um follow-up baseado em uma espera antiga seja disparado.
