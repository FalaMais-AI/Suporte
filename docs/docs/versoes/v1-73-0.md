# Versão 1.73.0

_Publicada em 09/09/2026._

## Privacidade por contato

Administradores agora podem restringir o acesso de usuários e cargos inferiores a contatos com atendimentos confidenciais. A configuração vale para as conversas atuais e para as próximas conversas daquele contato, em diferentes canais.

O controle está disponível nos detalhes do contato e nas conversas vinculadas. Alterações de acesso atualizam as telas abertas; permissões gerais ou atribuição de atendimento não liberam um contato bloqueado para aquele usuário.

📖 **Saiba mais:** [Privacidade dos contatos](../contatos/privacidade.md).

## Correção no cadastro de contatos

Corrigimos a remoção de CPF/CNPJ quando uma integração solicita limpar esse campo do contato.

📖 **Saiba mais:** [Cadastro de contatos](../contatos.md).
