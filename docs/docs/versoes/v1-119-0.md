# Versão 1.119.0

_Publicada em 29/10/2026._

## ✨ Novidades

- O Copiloto ficou mais inteligente para todas as empresas. Agora ele consulta os dados do sistema quantas vezes precisar para responder, lembra do que foi conversado antes na mesma conversa e só mostra números que vieram de fato das consultas. Quando não encontra algo, diz isso com o período e os filtros usados, em vez de inventar.

## 🔧 Melhorias

- A IA do atendimento ganhou mais tempo para pensar e agir em pedidos que exigem consultar a agenda, o CRM ou outras ferramentas. Pedidos mais demorados agora terminam com a ação feita, em vez de uma resposta genérica.
