# Versão 1.126.0

_Publicada em 02/11/2026._

## ✨ Novidades

### Copiloto

- O Copiloto agora monta um plano curto antes de consultar os dados e vai marcando o que já fez. Você acompanha os passos enquanto ele trabalha.
- Quando você pede para analisar os atendimentos, ele lê o conteúdo das conversas logo no começo, junto com os números. A leitura das conversas tem uma cota própria e não disputa espaço com as consultas.
- Se o tempo ou o limite de consultas de uma pergunta acabar, a resposta diz o que ficou de fora e traz o botão **Continuar a análise**, que retoma de onde parou.

## 🔧 Melhorias

### Copiloto

- Respostas mais cuidadosas: o Copiloto informa o período analisado, explica quando dois números do mesmo assunto não batem e apresenta causas como hipótese, não como certeza.
- Quando uma consulta falha duas vezes do mesmo jeito, ele muda de abordagem em vez de repetir.
- Consultas sobre encerramentos, atribuições, tarefas, agenda e mensagens agendadas ficaram muito mais rápidas.
- Uma consulta lenta de uma pessoa não pausa mais as consultas do Copiloto para a empresa inteira.
- Filtros com valor escrito de outro jeito (por exemplo, status de negócio) são corrigidos na hora, em vez de devolver zero.

## 🐛 Correções

- Os números diários usados pelo Copiloto voltam a cobrir os últimos 90 dias em todas as empresas. Em parte delas, o histórico começava só em 28/10.
