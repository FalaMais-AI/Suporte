# Versão 1.134.0

_Publicada em 16/11/2026._

## ✨ Novidades

- **Relatórios de atendimento pela API.** Agora a sua integração consegue saber, para cada atendimento:
  - quando o cliente chegou e quanto tempo esperou na fila;
  - quando um atendente assumiu e quando veio a primeira resposta humana;
  - quanto tempo durou e quem encerrou;
  - se o atendimento foi feito por uma pessoa, só pela IA ou por automação.

  Com esses dados você monta, no seu próprio sistema, os indicadores de atendimentos recebidos e atendidos, clientes sem atendimento humano, tempo de espera, tempo até a primeira resposta, transferências e produtividade por atendente e por equipe.
- **Histórico completo da conversa.** Cada atribuição, transferência entre atendentes ou equipes, volta para a fila e encerramento fica registrado e pode ser consultado pela API.
- **Novos avisos automáticos (webhooks).** O seu sistema passa a ser avisado quando uma conversa:
  - é criada;
  - é assumida por um atendente;
  - muda de equipe;
  - entra na fila;
  - recebe a primeira resposta humana;
  - é reaberta.
- **Quem enviou cada mensagem.** Pela API, cada mensagem agora diz se foi escrita pelo cliente, por um atendente, pela IA ou por uma automação.

## 🔧 Melhorias

- A documentação da API ganhou o guia "Métricas de atendimento", que mostra, para cada indicador, onde está o dado e como calcular.

## 🐛 Correções

- Uma chave de API ligada a um usuário com acesso restrito não consegue mais abrir, pelo número da conversa, conversas que esse usuário não vê no sistema.
