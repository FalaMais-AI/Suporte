# Versão 1.92.1

_Publicada em 05/10/2026._

## 🐛 Correções

### A tela "Confirmar email" não aparece mais para quem já confirmou o email

Algumas pessoas com o email já confirmado abriam o FalaMais.AI e caíam na
tela que pede o código de confirmação. O código não chegava, e o botão
"Reenviar código" não resolvia. Isso acontecia quando o navegador reabria o
endereço antigo dessa tela depois que o acesso tinha expirado.

Agora essa tela só aparece para quem está conectado e ainda precisa confirmar
o email. Se o acesso tiver expirado, você vai para a tela de entrada. Depois
de entrar com seu email e senha, você segue direto para o sistema.
