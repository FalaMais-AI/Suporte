# Versão 1.40.0

_Publicada em 05/08/2026._

Agora você pode falar sobre o cliente direto na negociação e a plataforma
organiza isso em uma anotação.

## ✨ Novidades

- **Anotação por áudio na negociação.** Nas notas do card, use o microfone (ou
  envie um arquivo de áudio) para contar o contexto do cliente. O FalaMais
  transcreve, organiza no formato das suas anotações (usando o template da
  empresa quando houver) e cria a nota automaticamente — com o áudio original
  anexado quando possível.
