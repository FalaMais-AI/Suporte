# Versão 1.122.1

_Publicada em 31/10/2026._

## 🐛 Correções

### Copiloto

- Quando o Copiloto mostrava uma resposta visual, por exemplo uma tabela de atendentes, o cartão do relatório usado para chegar nela aparecia logo abaixo com os mesmos números. Agora aparece só a resposta visual.
- Colunas de tempo em minutos aparecem como duração, por exemplo "2h 33min" em vez de "153,21".
- O resumo do relatório de atendimentos não mostra mais nomes internos de campos. Agora diz, por exemplo, "agrupados por atendente".
