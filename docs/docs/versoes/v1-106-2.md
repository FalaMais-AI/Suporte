# Versão 1.106.2

_Publicada em 21/10/2026._

## 🐛 Correções

- A IA não passa mais a conversa para a equipe quando o cliente só pede para agendar ou pergunta o preço, se o seu prompt diz que ela deve conduzir o atendimento. A transferência segue exatamente os casos que você escreveu ao lado da ação "Transferir para humano".
- A lista de ações autorizadas no fim do prompt voltou a ser só uma lista: a IA não tenta mais executar todas elas (como enviar um vídeo ou transferir) no primeiro contato.
- Quando a IA transfere a conversa para a equipe, ela não deixa mais uma pergunta para o cliente responder, já que não lerá a resposta.
