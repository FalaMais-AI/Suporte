# Versão 1.76.0

_Publicada em 13/09/2026._

## Consultas do dashboard

Reduzimos o trabalho repetido quando o mesmo dashboard é aberto simultaneamente e otimizamos o cálculo dos horários de pico. A preparação do resumo de IA também aproveita consultas simultâneas, mantendo as permissões de acesso.

📖 **Saiba mais:** [Dashboard](../relatorio/dashboard.md)

## Integrações mais previsíveis

A criação de uma tag que já existe passa a informar o conflito corretamente. Também melhoramos o tratamento de conflitos temporários durante a identificação de contatos com números internacionais.

📖 **Saiba mais:** [Contatos](../contatos.md) · [Mensagens](../msg.md)

## Ajuste de instalações próprias

O instalador passa a calcular limites conservadores conforme os recursos detectados e a configuração local ou externa dos serviços. Ajustes personalizados do operador são preservados. Quando não consegue determinar um limite com segurança, mantém a configuração e informa a necessidade de revisão.

Para instalações existentes, abra a nova cópia do instalador oficial antes de escolher **Atualizar**. O dimensionamento ajuda a distribuir os recursos; não representa uma garantia de volume ou tempo de resposta.

📖 **Saiba mais:** [FalaMais On-Premise](../on-premise.md)
