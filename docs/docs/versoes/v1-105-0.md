# Versão 1.105.0

_Publicada em 19/10/2026._

## ✨ Novidades

### Filtrar negociações pelas tarefas

- Em **Filtros**, no funil, há uma nova seção **Tarefas** com quatro opções:
  - **Com tarefa atrasada**: mostra as negociações com alguma tarefa vencida,
    de qualquer pessoa da equipe.
  - **Minhas tarefas atrasadas**: mostra só as negociações em que você tem
    uma tarefa vencida. Vale para as tarefas atribuídas a você, mesmo que o
    responsável pela negociação seja outra pessoa.
  - **Sem próxima ação**: mostra as negociações sem nenhuma tarefa em aberto,
    para encontrar os leads que ficaram sem acompanhamento.
  - **Todas**: sem restrição, como antes.
- O filtro funciona junto com os outros filtros e também na visão em tabela.
  Dica: combine **Sem próxima ação** com o status **Abertos** para ver só as
  negociações que ainda estão em andamento.

📖 **Saiba mais:** [Funil de vendas](../funil/funil.md)

## 🔧 Melhorias

- Quando uma tarefa vence com o funil aberto, o cartão, o contador da etapa e
  o filtro passam a mostrá-la como atrasada em até um minuto, sem recarregar a
  página.
- Quando você ou alguém da equipe conclui, cria ou altera uma tarefa de uma
  negociação, o funil se atualiza sozinho em poucos segundos.

📖 **Saiba mais:** [Funil de vendas](../funil/funil.md)

## 🐛 Correções

- Concluir uma tarefa pelos detalhes da negociação agora atualiza o funil na
  hora. Antes, o cartão continuava mostrando a tarefa como atrasada até a
  página ser recarregada.
