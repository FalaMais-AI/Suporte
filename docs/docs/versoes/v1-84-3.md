# Versão 1.84.3

_Publicada em 25/09/2026._

## 🐛 Correções

- Respostas rápidas enviadas por um Fluxo, inclusive as que têm intervalos entre mensagens, passam a conferir novamente se a conversa e a etapa do funil continuam aptas antes de cada envio.
- Os intervalos configurados entre textos e botões agora são respeitados. Uma mensagem automática da própria sequência não é confundida com uma intervenção humana; se houver falha, as próximas mensagens não são disparadas.
