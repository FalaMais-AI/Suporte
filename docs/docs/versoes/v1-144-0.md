## ✨ Novidades

- Na Central de IA, a visão "Todos os canais" agora mostra **quem atende cada número**: se o canal
  segue o prompt principal ou usa um prompt próprio, e se a IA está ligada ou pausada em cada um.
- Um canal com prompt próprio pode **voltar a usar o prompt principal** com um clique. O prompt
  próprio fica guardado como rascunho, sem ser apagado.
- Agora dá para **pausar a IA em um número específico** sem precisar criar um prompt para ele.

## 🔧 Melhorias

- Ao abrir um canal, um aviso mostra se ele segue o prompt principal ou um prompt próprio.
- Antes de publicar um prompt em um canal que seguia o prompt principal, o sistema pede
  confirmação, para ninguém trocar o atendimento de um número sem perceber.
