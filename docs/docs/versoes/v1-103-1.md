# Versão 1.103.1

_Publicada em 18/10/2026._

## 🐛 Correções

- A IA voltou a enviar as mídias do prompt (vídeos, imagens e documentos)
  quando a conversa pede. Desde a versão 1.103.0 o envio era bloqueado e o
  cliente recebia apenas a mensagem de texto.
- A IA não envia mais a palavra "null" como legenda de uma mídia. Quando não
  há legenda, a mídia vai sem texto.
