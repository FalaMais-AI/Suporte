# Versão 1.41.0

_Publicada em 05/08/2026._

Quando uma negociação é perdida por timing, você já pode deixar o retorno
programado no funil.

## ✨ Novidades

- **Retorno automático de leads perdidos.** Ao marcar uma negociação como
  perdida, você pode escolher uma data e uma etapa aberta do funil. Na data
  combinada, o FalaMais recria o card nessa etapa (a negociação perdida
  permanece no histórico). Dá para cancelar o retorno enquanto ele estiver
  pendente.
