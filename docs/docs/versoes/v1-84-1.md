# Versão 1.84.1

_Publicada em 24/09/2026._

## 🔧 Melhorias

- O assistente passa a seguir as ações condicionais do prompt quando os fatos da conversa confirmam a condição e a ação está autorizada. A lista de ações disponíveis, por si só, não obriga uma execução.

📖 **Saiba mais:** [Prompt do assistente](../assistente/prompt.md) · [Autonomia](../assistente/autonomia.md)

## 🐛 Correções

- Corrigimos casos em que a IA interrompia uma resposta útil e enviava uma mensagem genérica de falha porque interpretava uma instrução condicional do prompt como ação obrigatória naquele momento.
- Quando uma resposta repetida precisa de correção, o atendimento tenta uma nova formulação. Se ainda falhar, a conversa permanece sinalizada para tratamento e o contato recebe uma resposta de falha, em vez de ficar sem retorno.
