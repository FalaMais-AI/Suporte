# Versão 1.39.8

_Publicada em 31/07/2026._

## 🐛 Correções

- Quando a IA precisa revisar uma resposta e não consegue concluir a revisão,
  ela agora envia uma orientação segura para o cliente em vez de deixar a
  conversa sem resposta.
- Em imagens e comprovantes sem dados legíveis, a IA passa a pedir o reenvio
  com mais nitidez ou as informações necessárias, como valor e data, antes de
  confirmar qualquer resultado.
- Reforçamos a proteção das atualizações internas para evitar que uma
  atualização incompleta prejudique as rotinas automáticas.
