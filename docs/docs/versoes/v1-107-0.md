# Versão 1.107.0

_Publicada em 22/10/2026._

## ✨ Novidades

- Com a opção **Quebrar mensagens longas** ligada, a IA agora responde como uma pessoa digitando no WhatsApp: cada parágrafo chega como uma mensagem separada, sem linhas em branco dentro do balão. É a própria IA que escolhe onde quebrar, sempre em um ponto natural: o sistema nunca corta uma frase no meio.
- A IA conduz melhor a conversa: normalmente responde em 1 a 3 mensagens curtas e nunca manda mais de 5 de uma vez. Quando há muita informação, ela responde o essencial e deixa o resto para a próxima troca.
- No WhatsApp, a IA usa a formatação do próprio aplicativo para deixar as mensagens mais fáceis de ler: destaca em negrito o que o cliente não pode perder, como preço, data ou nome do produto, e mostra as opções em lista. Se o seu prompt pedir outro estilo, ele é respeitado.

📖 **Saiba mais:** [Prompt do assistente](../assistente/prompt.md)

## 🔧 Melhorias

- O campo de tamanho das mensagens agora se chama **Tamanho máximo por mensagem**: a IA escreve cada mensagem dentro desse limite. Um link longo nunca é quebrado.
