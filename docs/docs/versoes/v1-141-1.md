## 🐛 Correções

- **Exclusão de contato (LGPD) não apaga mais arquivos de outras conversas.** Quando uma mídia tinha sido encaminhada para outra conversa, excluir o contato original podia remover o arquivo da outra conversa também. Agora o arquivo só é apagado quando nenhuma outra conversa o utiliza.
- **Formulários:** dois envios simultâneos do mesmo contato não geram mais erro; o segundo é registrado junto ao primeiro.
