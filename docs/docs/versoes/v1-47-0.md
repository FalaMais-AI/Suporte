## ✨ Novidades

- A Sócios AI agora pode administrar clientes On-Premise por uma API segura:
  clientes, planos, limites, funcionalidades, instalações, usuários e canais
  WhatsApp ficam disponíveis para o painel deles, com isolamento por parceiro.
- Os comandos que dependem do servidor do cliente são sincronizados com
  segurança por uma conexão de saída autenticada. Isso funciona mesmo quando o
  cliente está atrás de firewall.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)

## 🔧 Melhorias

- Operações demoradas agora podem ser acompanhadas por status e webhooks
  assinados. Repetições seguras evitam duplicar criações ou alterações.
- QR Code e credenciais de provedores continuam somente no ambiente do cliente;
  a integração recebe apenas o estado necessário para acompanhar a operação.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)

## 🐛 Correções

- Mantivemos a proteção de licença de sete dias para empresas criadas fora dos
  fluxos oficiais e restringimos os provedores WhatsApp à UAZAPI e à API
  Oficial/Cloud API.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)
