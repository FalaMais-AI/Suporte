# Versão 1.44.0

_Publicada em 09/08/2026._

## ✨ Novidades

- O FalaMais.AI agora conta com uma edição On-Premise para organizações que
  precisam operar o sistema em sua própria infraestrutura.
- A instalação é guiada e as contas criadas nessa edição recebem uma identidade
  exclusiva para acompanhamento de licenciamento, sem enviar dados de clientes
  ou conversas para fora do ambiente da organização.

📖 **Saiba mais:** [FalaMais On-Premise](../on-premise.md).

## 🔧 Melhorias

- Atualizações da edição On-Premise passam a ser disponibilizadas como versões
  verificadas, para que o administrador possa atualizar a instalação com
  segurança pelo instalador.

📖 **Saiba mais:** [FalaMais On-Premise](../on-premise.md).
