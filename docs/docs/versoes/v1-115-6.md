# Versão 1.115.6

_Publicada em 28/10/2026._

## 🐛 Correções

- As conversas voltam a se atualizar sozinhas depois de uma queda de conexão. Antes, se a internet oscilava ou o computador saía do modo de espera, a tela podia parar de mostrar mensagens novas até alguém recarregar a página. Agora o sistema continua tentando se reconectar até conseguir.
- Todas as pessoas da equipe passam a ver as mensagens novas ao mesmo tempo. Em alguns momentos, uma atendente via a mensagem e a outra não.
- A lista de conversas confere novidades a cada minuto, mesmo com a conexão ativa, para que nada fique para trás.
- Uma instabilidade rápida do servidor no momento em que a página abre não tira mais você do sistema. A página espera o servidor responder e continua com o seu acesso.
- Mensagens agendadas para um horário que já passou não são mais enviadas na hora. O sistema avisa que o horário escolhido já passou e pede um horário futuro.
