# Versão 1.42.0

_Publicada em 06/08/2026._

A integração com a Digital Grid fica mais simples de configurar e passa a
enviar a fatura com o PDF anexado na conversa.

## ✨ Novidades

- **Fatura da Digital Grid com PDF anexado.** Quando uma fatura é registrada,
  o cliente recebe a mensagem formatada e o PDF da fatura como anexo no
  WhatsApp (em vez de só um link na mensagem).
- **Configuração mais simples.** Em Integrações Externas → Digital Grid, você
  configura canal, mensagem e anexo sem precisar lidar com caminhos técnicos
  do webhook no dia a dia.
- **Suporte à API Oficial da Meta.** Se o canal for Oficial, a integração usa
  um modelo de utilidade com o PDF no cabeçalho. Basta enviar o modelo para
  aprovação da Meta e acompanhar o status na própria tela.

## 🔧 Melhorias

- A mensagem de fatura traz campos prontos como instalação, valor, economia,
  competência e vencimento, com formatação clara em reais e datas.
- É possível usar um modelo sugerido de texto (com emojis) no WhatsApp
  convencional e personalizar como quiser.
