## ✨ Novidades

- A criação de uma conta no On-Premise agora pode continuar do ponto em que
  parou quando a conexão ou o processamento local sofre uma interrupção.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)

## 🔧 Melhorias

- A aprovação central e a criação local trabalham juntas com mais segurança:
  a mesma solicitação reaproveita a conta reservada e não cria cobranças ou
  administradores duplicados.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)

## 🐛 Correções

- Corrigido o caso em que uma tentativa interrompida deixava a conta marcada
  para aprovação, mas uma nova tentativa não conseguia concluir a ativação.
- Corrigida a sincronização de dados para garantir que uma instalação só
  atualize contas autorizadas para ela.

📖 **Saiba mais:** [Integração da API Super Admin](../onpremise-super-admin.md)
