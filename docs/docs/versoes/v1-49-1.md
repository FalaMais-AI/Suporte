# Versão 1.49.1

_Publicada em 18/08/2026._

## 🐛 Correções

- Após atualizar uma instalação On-Premise, agora é possível criar o primeiro
  acesso de Super Admin diretamente pelo menu do instalador.
- A senha é digitada de forma protegida e não aparece na confirmação, que
  mostra apenas o nome e o e-mail do acesso criado.
