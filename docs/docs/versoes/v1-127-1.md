# Versão 1.127.1

_Publicada em 03/11/2026._

## 🐛 Correções

- A IA não envia mais anotações internas para os seus clientes. Em alguns atendimentos, o texto que acompanha um vídeo começava com uma anotação como "[Mídia enviada: vídeo…]", e em um caso isolado chegou uma mensagem só com "[SPLIT]". Essas anotações agora são removidas antes do envio, e o restante da mensagem chega normalmente. Os vídeos sempre foram entregues.
