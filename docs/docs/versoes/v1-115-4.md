# Versão 1.115.4

_Publicada em 28/10/2026._

## 🐛 Correções

- Quando a IA leva uma negociação para uma etapa de ganho ou de perda e, na mesma resposta, também a fecha e registra a nota, a nota agora é sempre gravada. Antes, em alguns atendimentos a nota se perdia, e os fluxos que enviam a última nota da negociação (como o aviso para a equipe) saíam sem ela.
