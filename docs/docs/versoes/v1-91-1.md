# Versão 1.91.1

_Publicada em 04/10/2026._

## 🔒 Segurança

### Troca de e-mail agora exige confirmação

Quando você muda o e-mail da sua conta em **Configurações → Segurança**, o
novo endereço precisa ser confirmado antes de usar o sistema. Enviamos na hora
um código para o novo e-mail; é só digitar o código na tela de confirmação que
aparece em seguida. Isso garante que só o dono do endereço consiga usá-lo,
inclusive em convites para outras empresas.

Se o código não chegar, peça um novo na própria tela de confirmação.
