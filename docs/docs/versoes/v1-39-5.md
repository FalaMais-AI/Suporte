# Versão 1.39.5

_Publicada em 28/07/2026._

## 🐛 Correções

- Corrigimos uma situação em que instruções internas do assistente poderiam
  aparecer como uma mensagem automática na conversa.
- Chamadas de ação que chegarem nesse formato agora são interpretadas com
  segurança quando estiverem disponíveis. Caso não possam ser executadas, o
  conteúdo interno é bloqueado e o assistente prepara uma resposta normal para
  o cliente.
- Textos válidos escritos junto da instrução interna continuam preservados.
