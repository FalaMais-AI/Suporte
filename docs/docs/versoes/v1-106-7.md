# Versão 1.106.7

_Publicada em 21/10/2026._

## 🐛 Correções

- Quando a IA passa a conversa para a equipe, o cliente sempre recebe a mensagem avisando, mesmo que tenha mandado outra mensagem logo em seguida. Antes, nesse caso, a conversa podia ficar pausada sem nenhuma resposta.
- A IA só transfere para a equipe nos casos que o seu prompt realmente pede. Ela não passa mais a conversa adiante em perguntas de preço ou agendamento quando o prompt não manda.
