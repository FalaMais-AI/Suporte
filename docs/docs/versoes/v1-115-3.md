# Versão 1.115.3

_Publicada em 27/10/2026._

## 🐛 Correções

- As mensagens de template enviadas pela API oficial do WhatsApp agora aparecem no chat do jeito que o contato recebe: o texto com as quebras de linha, o rodapé em letra menor e os botões logo abaixo, em vez de tudo misturado num texto só.
- Templates enviados por fluxos e integrações (como confirmações de consulta) passam a aparecer na conversa, para a equipe ver exatamente o que foi enviado.
