# Versão 1.117.0

_Publicada em 29/10/2026._

## ✨ Novidades

- Quando uma mensagem não consegue ser enviada, ela continua na conversa marcada como não enviada, com o motivo e o botão "Reenviar". Antes, a mensagem podia simplesmente sumir. Ao reenviar, o sistema garante que o cliente não recebe a mensagem duas vezes.
- Nas empresas que usam a API oficial do WhatsApp, agora é possível ligar a confirmação de leitura: quando um atendente abre a conversa, o cliente passa a ver que a mensagem foi lida. A opção fica em Configurações da empresa e vem desligada.

## 🔧 Melhorias

- Áudios gravados ficam mais confiáveis: gravações vazias ou curtas demais não são enviadas, o microfone é sempre liberado e o sistema avisa quando uma gravação é descartada. Também funcionam gravações feitas no iPhone.
- O envio de áudio responde mais rápido: se o servidor estiver ocupado, você recebe um aviso em poucos segundos em vez de ficar esperando.
- Se uma versão nova do sistema sair enquanto você grava um áudio ou envia um arquivo, o aviso de atualização pergunta antes de recarregar.
- Clientes que escreveram primeiro pelo canal oficial sem mostrar o número não ficam mais em uma conversa separada: quando o número aparece, as conversas são unidas no mesmo contato.

## 🐛 Correções

- Mensagens agendadas pela IA ou por follow-ups para "agora" voltam a funcionar, e um horário escrito sem fuso é lido no fuso da sua empresa.
- Editar o horário de uma mensagem agendada não perde mais o envio.
- A ordem das mensagens com o mesmo horário fica igual em todas as telas.
