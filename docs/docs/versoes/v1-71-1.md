# Versão 1.71.1

_Publicada em 05/09/2026._

## Armazenamento S3 mais fácil de encontrar

**Armazenamento S3** agora aparece no menu principal do instalador e como
primeira opção ao abrir **Variáveis**. As opções são exibidas imediatamente,
sem precisar pular uma lista de variáveis ausentes.

O preenchimento das variáveis ausentes passou a ser uma ação separada e
opcional. As opções de Variáveis aparecem uma por linha, facilitando a leitura.

Execute novamente o instalador atualizado para acessar o novo menu. Esta
correção melhora a navegação e não exige reinstalar a aplicação.
