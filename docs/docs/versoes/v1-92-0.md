# Versão 1.92.0

_Publicada em 05/10/2026._

## ✨ Novidades

### A IA divide a resposta em mensagens naturais

Quando a opção **Quebrar mensagens longas** está ligada, a própria IA agora
escreve a resposta já separada em mensagens curtas, cada uma com um assunto,
como uma pessoa faria no WhatsApp. O cliente recebe as mensagens em
sequência, com uma pequena pausa entre elas.

O tamanho configurado é apenas uma referência: a IA não precisa cortar
exatamente nele. Para respostas muito longas, o sistema continua garantindo
que nenhuma mensagem passe do limite do canal.

### O teste do agente mostra exatamente o que o cliente recebe

No Playground, a resposta aparece dividida do mesmo jeito que chegaria ao
cliente no WhatsApp, com as mesmas mensagens e na mesma ordem.

## 🔧 Melhorias

- O texto da configuração **Quebrar mensagens longas** foi atualizado para
  explicar que o tamanho é uma referência.
