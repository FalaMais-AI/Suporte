# Versão 1.71.0

_Publicada em 05/09/2026._

## Contato comercial nas instalações On-Premise

O administrador pode definir um WhatsApp comercial para cada empresa e um
número geral para as empresas sem contato próprio. Ao terminar o período de
teste, o botão de contato usa o número configurado para aquela empresa.

📖 **Saiba mais:** [Administração On-Premise](../onpremise-super-admin.md)

## Configure o S3 sem reinstalar

O menu de variáveis da instalação agora permite adicionar ou alterar o S3.
A conexão é testada antes de aplicar a mudança, com backup e restauração da
configuração anterior em caso de falha. Os arquivos locais antigos continuam
acessíveis, enquanto os novos uploads passam a usar S3.

É necessário atualizar a aplicação e o instalador. Os arquivos locais são
preservados, não transferidos automaticamente. A troca entre buckets exige a
cópia prévia dos arquivos para o novo destino.

📖 **Saiba mais:** [Armazenamento On-Premise](../onpremise-super-admin.md#armazenamento-s3-sem-reinstalar)

## Número correto nos canais conectados

Os canais conectados pelo conector passam a buscar o telefone completo, com o
código do país. A sincronização também atualiza canais existentes quando o
provedor disponibiliza essa informação.

📖 **Saiba mais:** [Configuração de canais](../configuracao/canais.md)

## Seleção de modelos mais legível

As configurações gerais exibem os modelos de IA com nomes, recursos e preços
organizados, sem sobreposição de textos em telas menores.

📖 **Saiba mais:** [Administração On-Premise](../onpremise-super-admin.md#configurações-gerais)
