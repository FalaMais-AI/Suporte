# Versão 1.85.0

_Publicada em 28/09/2026._

## ✨ Novidades

### Responder conversas da fila ficou mais simples

Agora, quando você responde uma conversa que ainda está sem responsável (na fila) e você tem permissão para atendê-la, o sistema **assume a conversa automaticamente para você** no momento do envio. Vale também para conversas abertas a partir da aba Contatos.

Quem atende as filas por time também passou a conseguir **pegar conversas roteadas para o próprio time** pelo botão de pegar, sem precisar de uma permissão extra de fila geral.

📖 **Saiba mais:** [Mensagens](../msg.md) · [Filas](../configuracao/usuarios/fila.md)

## 🔧 Melhorias

### Conversa aberta sempre atualizada

Quando uma conversa é assumida, transferida ou devolvida para a fila por outra pessoa, a tela de conversa que você está vendo se atualiza sozinha. Não é mais necessário sair e voltar na conversa para conseguir responder.

📖 **Saiba mais:** [Mensagens](../msg.md)

### Permissões de fila mais claras

Na tela de funções, a opção **"Pegar da fila"** agora deixa claro que só funciona com o escopo "Todas as conversas" ou "Somente não atribuídas". Ao trocar o escopo, a opção é ajustada automaticamente, evitando configurações que pareciam ativas mas não funcionavam.

📖 **Saiba mais:** [Funções](../configuracao/usuarios/funcao.md)

## 🐛 Correções

- Conversas que estavam com um administrador não aparecem mais como "sem responsável": agora o sistema explica que a conversa está em atendimento por administrador e permite assumir para responder.
- Ao tentar enviar para uma conversa que pertence a outro time, o aviso agora é específico ("conversa direcionada para outro time ou cargo"), em vez de um erro genérico.
- Quando o número de destino não tem WhatsApp, o aviso agora é claro ("o número informado não está no WhatsApp"), em vez de uma mensagem genérica de erro.
