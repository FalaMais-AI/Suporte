# Versão 1.102.1

_Publicada em 15/10/2026._

## 🐛 Correções

- A IA não pausa mais sozinha quando o cliente pede para agendar e o seu
  prompt não manda passar o agendamento para a equipe. Antes, uma mensagem
  como "Quero agendar uma avaliação", inclusive o texto pronto de um anúncio,
  fazia a IA chamar a equipe e parar de responder logo na primeira mensagem,
  sem criar a negociação nem agendar os follow-ups. Agora a IA segue o seu
  prompt: se ele manda acolher e qualificar o cliente antes de passar para a
  equipe, é isso que ela faz. Se o seu prompt manda passar pedidos de
  agendamento direto para uma pessoa, isso continua funcionando como antes.
