# Versão 1.121.0

_Publicada em 31/10/2026._

## ✨ Novidades

- O Copiloto agora consulta os dados da sua empresa para responder perguntas como "quantos negócios fechamos este mês?" ou "quais conversas estão sem resposta?". Ele só enxerga o que o cargo de quem pergunta já pode ver no sistema: o que você não vê na tela, o Copiloto também não vê.
- As respostas ganham blocos visuais: números em destaque, tabelas, gráficos, comparações e listas, em vez de só texto corrido.
- Você pode anexar arquivos à mensagem: PDF, planilha (XLSX ou CSV) e imagem. O Copiloto lê o arquivo e usa o conteúdo na resposta, por exemplo para comparar uma planilha com o que está no sistema.
- Relatórios em PDF: abaixo de uma resposta com dados aparece o botão "Gerar PDF". Você acompanha o preparo e baixa o arquivo quando ficar pronto.
- Controles de privacidade por empresa: quem administra o assistente pode desligar, por empresa, a consulta aos dados, a leitura de mensagens, os anexos e os relatórios em PDF. Cada mudança fica registrada.

## 🔧 Melhorias

- A retenção dos dados do Copiloto passa a ser medida: nesta versão o sistema só conta o que já passou do prazo, sem apagar nada. A limpeza automática será ligada em seguida.
