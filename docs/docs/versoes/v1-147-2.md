# Versão 1.147.2

_Publicada em 27/11/2026._

## 🐛 Correções

### Listas respeitam o que cada usuário pode ver

- Em **Listas → Ver contatos**, cada usuário agora vê apenas os contatos que
  a função dele permite ver, exatamente como na tela de Contatos. Um usuário
  que vê só os próprios contatos (ou só os da equipe) não vê mais nome,
  e-mail e telefone de outros contatos da lista.
- A mesma regra vale para quem consulta listas pela API: a chave de API
  enxerga somente os contatos que o dono da chave pode ver. Uma chave cujo
  dono não faz mais parte da empresa não traz nenhum contato.
