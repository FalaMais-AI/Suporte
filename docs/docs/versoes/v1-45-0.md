# Versão 1.45.0

_Publicada em 11/08/2026._

## ✨ Origem de leads mais completa

- Os cadastros vindos das páginas do FalaMais agora preservam melhor a origem
  da campanha. Assim, quando um lead chega ao CRM, a equipe tem uma base mais
  confiável para acompanhar o resultado da aquisição.

📖 **Saiba mais:** [Hub de Conversão](../configuracao/conversao.md)

## 🔧 Mais leve e respeitando sua escolha

- A medição das páginas públicas foi simplificada para reduzir carregamentos
  desnecessários. Os dados de campanha só são coletados após a sua escolha de
  consentimento.

📖 **Saiba mais:** [Hub de Conversão](../configuracao/conversao.md)

## 🖥️ Instalação local com a marca do cliente

- A instalação On-Premise agora conduz o responsável técnico pelas
  configurações essenciais e já prepara o ambiente com o nome, logos e ícone
  do cliente. O primeiro teste pode ser feito com UAZAPI ou API Oficial.

📖 **Saiba mais:** [Edição On-Premise](../on-premise.md)
