# Versão 1.100.0

_Publicada em 13/10/2026._

## ✨ Novidades

### Requisição HTTP com assinatura HMAC nos fluxos

- A etapa **Requisição HTTP** agora pode assinar cada envio com uma chave
  secreta (assinatura HMAC), como pedem muitos CRMs e sistemas externos.
  Você escolhe o algoritmo, os cabeçalhos e o texto que é assinado.
- A chave secreta é digitada uma única vez. Depois de salvar o fluxo, ela
  fica protegida e aparece apenas com os primeiros caracteres
  (por exemplo, `9bfr••••••••`). Para trocar ou remover, use os botões ao
  lado do campo.
- Por segurança, se você mudar o endereço de destino ou o texto assinado,
  a chave precisa ser digitada de novo.

### Mais dados disponíveis nos fluxos

- As etapas **Requisição HTTP**, **Definir Campos** e **Mapear Campos**
  agora podem usar as notas da negociação, as notas, a localização e a
  origem do contato, a campanha e a data e hora atuais.

## 🔧 Melhorias

- Na **Requisição HTTP**, o campo avançado **Repetir nos status** define
  em quais respostas de erro o fluxo deve tentar de novo.
