# Versão 1.39.0

_Publicada em 24/07/2026._

## ✨ Novidades

- As referências (@) do editor de prompt viraram cartõezinhos coloridos com o
  ícone de cada tipo — ações, funis, etapas, tags, fluxos, listas, ferramentas
  e mídias. Ficou muito mais fácil localizar cada funcionalidade no meio do
  texto, como em editores modernos de anotações.
- O painel que abre ao digitar @ também voltou a mostrar os ícones coloridos,
  agora com os resultados organizados por grupo e com uma descrição em cada
  item para você escolher com segurança.

## 🔧 Melhorias

- Cada referência agora se comporta como um bloco único: as setas pulam o
  cartão inteiro e o apagar remove a referência de uma vez, sem deixar
  pedaços de código no texto.
- Você pode confirmar a referência destacada com Enter ou Tab.
- As referências nas mensagens dos Fluxos e dos Follow-ups ganharam os mesmos
  ícones, mantendo o visual consistente em toda a plataforma.
