# Versão 1.76.3

_Publicada em 14/09/2026._

## 🐛 Correções

A lista de conversas agora se mantém estável enquanto novos atendimentos, transferências e atualizações chegam em tempo real.

- Corrigimos uma situação rara em que dados temporários incompletos podiam interromper a atualização da lista.
- Conversas atribuídas, encerradas ou reabertas passam a refletir o novo estado de maneira mais consistente.
