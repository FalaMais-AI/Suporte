# Versão 1.102.3

_Publicada em 17/10/2026._

## 🐛 Correções

### Follow-up com template oficial

- Quando um follow-up é enviado com um template oficial do WhatsApp, a
  conversa agora mostra o texto que o cliente recebeu, com os botões do
  template. Antes, aparecia só "Template oficial:" seguido do nome do
  template, mesmo com a mensagem completa chegando normalmente ao cliente.
