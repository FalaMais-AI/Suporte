## ✨ Novidades

- **Ambiente de testes (sandbox) para integrações.** Agora o administrador da empresa pode criar o próprio ambiente de testes em **Configurações**, separado da operação real. Lá dentro os envios são simulados (nada é enviado de verdade para os seus clientes), as chaves de API começam com `fm_test_` e usam o mesmo endereço da API. Para entrar, basta clicar em **Abrir sandbox**: não é preciso outra senha. Quem sair da empresa perde o acesso ao sandbox também.

## 🐛 Correções

- **Botão "Nova negociação" no painel do contato.** Em contatos com duas ou mais negociações, o botão ficava escondido, e não dava para registrar uma recompra ou renovação pela conversa. Agora ele aparece sempre no topo da aba **Negociação**, e a negociação criada já fica selecionada.
