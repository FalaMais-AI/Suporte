# Versão 1.39.1

_Preparada em 24/07/2026. A publicação será feita junto ao deploy de produção._

## 🐛 Correções

- O assistente agora considera o conteúdo de áudios e imagens recebidos antes
  de responder. Notas de voz passam a ser entendidas pela transcrição, e as
  imagens podem ter o texto visível e os elementos importantes considerados na
  conversa.
- Quando uma mídia ainda está chegando, a resposta aguarda o preparo do
  arquivo. Se ele não ficar disponível, o atendimento segue normalmente com a
  legenda ou o texto que o cliente enviou.
