# Versão 1.131.0

_Publicada em 09/11/2026._

## ✨ Novidades

- Notas do negócio: cada nota mostra quando foi criada e, se alguém mudou o texto depois, quando foi editada pela última vez, com dia e hora no fuso da sua empresa. Passe o mouse sobre a data para ver há quanto tempo foi.
- Negócios copiados para outro funil mostram **Copiado em** com a data da cópia no topo do negócio, ao lado da etapa. As notas que vieram junto ganham o selo **Copiada**. Passe o mouse no selo para ver quando a cópia foi feita.

📖 **Saiba mais:** [Funil de vendas](../funil/funil.md)

## 🐛 Correções

- Ao copiar um negócio para outro funil, as notas passavam a aparecer como recém-criadas (por exemplo, "7min"), mesmo tendo sido escritas dias antes. Agora a cópia mantém a data original de cada nota e dos anexos. Os negócios copiados antes desta versão continuam com a data da cópia nas notas.
- Alguns prints feitos no iPhone eram recusados pelo WhatsApp na API Oficial, porque o arquivo tem mais cores do que o WhatsApp aceita. Agora o FalaMais ajusta a imagem automaticamente antes de enviar.
- Quando uma mensagem não é entregue, o chat mostra o motivo completo informado pelo WhatsApp.
- As mensagens de erro de configurações de IA, copiloto, ligações, permissões, login, usuários e equipes ficaram mais claras e agora dizem o que fazer em seguida.
