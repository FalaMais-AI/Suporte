# Versão 1.39.3

_Publicada em 28/07/2026._

## 🔧 Melhorias

- A compreensão de notas de voz ficou mais resiliente. Se o serviço principal
  de transcrição estiver temporariamente indisponível ou devolver um resultado
  vazio, o atendimento tenta uma opção de segurança antes de seguir sem o
  conteúdo do áudio.
- O processamento interno do assistente passou a usar rotas mais diretas para
  organizar o contexto das conversas, mantendo serviços alternativos
  disponíveis somente quando forem escolhidos pela equipe.

📖 **Saiba mais:** [Mensagens](../msg.md) ·
[Prompt do assistente](../assistente/prompt.md)

## 🐛 Correções

- Corrigimos casos em que uma solicitação mais complexa consumia todo o espaço
  de processamento antes de gerar a resposta visível.
- Se o assistente ainda produzir uma resposta vazia após a recuperação normal,
  o atendimento agora faz uma última tentativa segura com o serviço de
  contingência, sem repetir ações já executadas.
