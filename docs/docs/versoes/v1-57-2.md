## 🔧 Melhorias

- As análises do Assistente IA agora escolhem a forma mais útil para cada
  pedido. Perguntas simples podem receber uma resposta direta, enquanto
  comparações e análises maiores podem usar listas ou seções quando isso ajuda
  na leitura.
- O andamento de uma consulta passou a ter um indicador de carregamento claro,
  sem confundir uma atividade em curso com uma resposta concluída.

📖 **Saiba mais:** [Assistente IA (Copiloto Interno)](../copiloto.md)

## 🐛 Correções

- Corrigimos a repetição obrigatória de blocos como “leitura”, “risco” e
  “próxima ação”, que podia deixar respostas diferentes com aparência mecânica.
- Corrigimos o ícone parado durante uma consulta ativa; em dispositivos com
  movimento reduzido, o andamento continua identificado de forma acessível.
