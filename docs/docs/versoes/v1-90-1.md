# Versão 1.90.1

_Publicada em 04/10/2026._

## 🐛 Correções

### Mensagens apagadas aparecem na conversa

Quando o cliente apaga uma mensagem "para todos" no WhatsApp, a conversa agora
mostra o aviso **"Mensagem apagada"** no lugar dela, como no próprio WhatsApp.
Antes, se as últimas mensagens de uma conversa tivessem sido apagadas, a
conversa abria vazia, sem explicação. O conteúdo apagado continua sem ser
exibido.

### Contador de não lidas mais preciso

Mensagens que o cliente apagou deixam de contar como não lidas. As conversas
que já estavam com o contador alto por causa de mensagens apagadas foram
corrigidas automaticamente.
