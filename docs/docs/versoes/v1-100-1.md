# Versão 1.100.1

_Publicada em 13/10/2026._

## 🐛 Correções

### Follow-up com "agendar próximo" não se repete mais

- Quando uma regra de follow-up usa a ação final "agendar próximo", a
  mensagem extra agora é enviada uma única vez. Antes, a última mensagem da
  sequência podia voltar a ser enviada todo dia para o mesmo contato.
