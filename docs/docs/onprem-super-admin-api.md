# API de Super Admin On-Premise

Os recursos administrativos da instalação On-Premise ficam disponíveis depois
que o primeiro Super Admin é criado e a licença da instalação está válida.

## Antes de integrar

- Crie o primeiro Super Admin na própria instalação.
- Confirme que a licença está ativa.
- Gere e proteja as credenciais de integração na área administrativa.
- Use apenas sistemas e pessoas autorizadas pela sua empresa.

## Boas práticas

- Mantenha as credenciais fora de planilhas, mensagens e repositórios de
  código.
- Crie acessos separados para cada integração quando isso estiver disponível.
- Revogue uma credencial imediatamente se houver suspeita de exposição.
- Revise periodicamente quem tem permissão administrativa.

Para localizar os recursos e a documentação da API da sua instalação, acesse
**Integrações** no painel administrativo.
